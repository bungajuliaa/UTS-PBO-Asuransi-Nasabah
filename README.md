
# Aplikasi Asuransi Nasabah

Program ini dibuat untuk memenuhi Ujian Tengah Semester mata kuliah Pemrograman Berorientasi Objek I.

## Deskripsi
Aplikasi Asuransi Nasabah merupakan program berbasis CLI menggunakan Python untuk mengelola data nasabah asuransi kesehatan dan asuransi jiwa, serta data polis.

## Fitur
- Menambahkan data nasabah
- Menampilkan data nasabah
- Mencari data nasabah
- Mengubah data nasabah
- Mengecek status polis
- Keluar dari program

## Penerapan OOP
- Class dan Object
- Constructor
- Encapsulation
- Inheritance
- Association

## Struktur File
- main.py
- nasabah.py
- nasabah_kesehatan.py
- nasabah_jiwa.py
- polis.py

## Cara Menjalankan
Jalankan file main.py menggunakan Python.
